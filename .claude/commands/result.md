Run `npm run mix -- result <sample> --age=7|28 --mpa=<result> --lab=<report ref>`. The test date defaults to the sample date plus the age. If the result is below grade, say so and show `/low-strength`.

Ambiguous names list the candidates and stop: ask which one. Never send anything; drafts stay in `drafts/`.
